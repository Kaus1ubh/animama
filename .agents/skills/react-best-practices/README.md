# React Best Practices for Animama

Adapted from Vercel Engineering's [agent-skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices) for Animama's client-rendered React application.

`SKILL.md` defines scope and indexes the maintained `rules/` files. `AGENTS.md` points to those sources. This local copy does not include upstream build scripts or generated evaluation fixtures; no standalone pnpm build or install is required.

When updating from upstream, preserve the React/Vite/TanStack constraints in `SKILL.md`, review mixed examples as well as framework-specific rule files, and update the index when adding or removing rules.
