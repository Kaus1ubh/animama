# Animama Pocket TTS voice set

Voice states for Pocket TTS `english_2026-04`, hosted by Animama: its self-encoded
core voices and every voice downloaded on demand. Each file is a precomputed
flow LM voice state (`<voice>.safetensors`). See ATTRIBUTION.md for sources and
licenses; `scripts/voices/voices.py` in the Animama source reproduces the
self-encoded states.
