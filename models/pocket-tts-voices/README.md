# Animama Pocket TTS voice set

Voice states for Pocket TTS `english_2026-04`, hosted by Animama: the voices its app
downloads on demand and the self-encoded states of its core voices. Each file is a
precomputed flow LM voice state (`<voice>.safetensors`). See ATTRIBUTION.md for
sources and licenses; `scripts/voices/voices.py` in the Animama source reproduces
the self-encoded states.
