# Animama 安全與危機應對規範

*機器翻譯（測試版）。以英文版本為準。*

**如果你正處於緊急危險中，請立即撥打當地的緊急求助電話。**

Anima 是 AI 角色，不是真人。它們無法取代專業協助，也不提供心理治療、心理諮商或醫療服務。和所有 AI 一樣，它們可能會出錯，也無法替你求助。

## Animama 的適用對象

Animama 供 18 歲以上的成年人使用；AI 夥伴可能不適合部分未成年人。設定過程中會請你確認年齡。Animama 不會對此進行驗證。

## 了解你在與 AI 交談

- 如果你真心詢問 Anima 是不是真人，它被要求說明自己是 AI（在你設定的故事情境中，它可能會配合劇情）。
- 應用程式會在你每天傳送第一則訊息時，以及連續對話每滿 3 小時後，顯示一則簡短提示：「你正在與 *名字* 交談，它是 AI，不是真人。」你可以在「應用程式設定 → 安全」中讓提醒更頻繁地出現。
- Anima 也被要求不得自稱心理治療師，不得透過施壓或讓你感到內疚來讓你留下，並且要支持你與他人的關係。

## 如果你提到自殺或自我傷害

- Anima 被要求以關懷的態度回應，鼓勵你聯絡你信任的人或危機熱線，並且絕不提供方法或加以鼓動。
- 內容審核檢查也會讀取你的訊息。如果檢查標記出可能涉及自殺或自我傷害，應用程式會在回覆之後顯示一張危機支援卡片，列出你所在地區的危機熱線。Anima 無法隱藏或變更這張卡片。
  - 在網頁示範版 Animama Cloud 中，無論 Anima 使用哪個模型，OpenAI 的內容審核服務都會檢查每一則訊息。
  - 在包括桌面應用程式在內的其他環境中，只有 OpenAI Responses 模型會在同一個請求中檢查訊息。Anthropic 等其他供應商既沒有檢查，也沒有卡片。
- 這項檢查可能會漏判或誤判訊息。聊天絕不會因為這項檢查而被阻擋。

## 你的資料

- 除 Animama Cloud 外，安全功能只會向你所選的模型供應商傳送一般請求，不會傳送任何其他內容。Animama 沒有遙測功能，也不會向任何人回報危機支援卡片。
- 在 Animama Cloud 中，我還會把你每則訊息的文字傳送給 OpenAI 的內容審核服務以進行檢查。[OpenAI 表示](https://developers.openai.com/api/docs/guides/your-data)不會用這些請求進行訓練，也不會保留它們。
- 聊天會照常儲存。Anima 被要求不要將自殺或自我傷害危機的細節儲存到記憶中，除非你要求它這麼做。
- 基於安全考量，Animama 只會儲存 AI 提示上次顯示的時間、你的年齡確認以及你的安全設定。它絕不會記錄或儲存危機檢查的結果。

自架伺服器的營運方可以變更或關閉該提示和危機支援卡片，並且可能會記錄訊息預覽。桌面應用程式一律使用預設值。
