# Avatar Content And Appearance

This filename is retained for documentation continuity; current Avatars and
Appearance Images use Included/Local typed catalog items, not immutable release
selection. Reviewed loadout commands select logical items. A mounted runtime
pins exact revisions and adopts later source edits only after remount.

The Anima management Appearance dialog edits Profile and Background as
independent typed bindings. It can save a Local Appearance Image and frame it
with Fill/Fit, focal point, and zoom before a reviewed loadout commit. Upload
failure never changes the loadout; Cancel discards unsaved framing. Removing a
profile override permits the registered Avatar portrait fallback. Included
portraits and Local images use protected catalog delivery, not public storage
URLs or the old same-origin release manifest.

The browser has reusable VRM capture primitives and a development-only
`/a/avatar-portrait-debug` harness. The new creator reuses its own renderer for
portrait capture, then requires confirmation before the typed portrait Save
canonicalizes and admits an ordinary owner-scoped Appearance. Browsing Avatar
cards alone saves nothing. Included portraits must match the selected model;
Avatar changes invalidate an automatic portrait but retain custom images.
Capture failures offer retry/custom-image recovery or an explicit null-profile
warning. Optional
background Default means the normal app stage, not a saved image or legacy URL.

`/a/animas/new` is the four-step live creator. Existing Library,
preview, management, and creator-hub links retain their logical Avatar handoff;
a saved owner draft takes precedence over a new hint. The creator uses
validated typed references and complete expected source revisions; it creates
no Blueprint or publication. Confirmed Avatar/Appearance Saves remain My Content
after cancellation; unsaved files require reselection after reload. See the
[live creation guide](custom-anima-creation.md) and its
[acceptance status](custom-anima-creation.md#acceptance-and-regression-coverage).
