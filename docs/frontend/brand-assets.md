# Animama brand assets

Approved option 1: companion speech bubble with sky-blue rays and the rounded Animama wordmark.

Generated with the built-in imagegen tool from the owner-selected concept. Transparent PNG assets are used for the sidebar and browser favicon. The wordmark is an alpha mask so its color follows the sidebar theme. The mark has a warm backing in the sidebar for dark-theme contrast. Browser page title is Animama.

## Rendering and formats

The compact sidebar uses a slightly smaller mark with a one-pixel optical offset
right and up to balance the speech bubble and upper-right rays. Header layouts
stay mounted and crossfade with the sidebar width transition; inactive controls
are inert and hidden from accessibility APIs. Reduced-motion users skip the fade.

PNG originals preserve the approved generated artwork. A future vector master
should use true paths, including outlined wordmark lettering, checked against
these originals. Embedding PNG bytes inside SVG does not make the artwork vector.
Raster favicon sizes can be exported from that approved master when available.

## Generation prompts

### Mark

Use case: background-extraction. Edit target: supplied approved Animama option1 brand sheet. Extract/reproduce ONLY the large upper-left speech bubble companion icon as a single production logo asset. Preserve exactly the charcoal rounded speech bubble silhouette, warm ivory face, two oval eyes with small highlights, curved smile and three sky-blue rays at top right. Do not redesign. Remove everything else, all words, all other logos, swatches, shadows, glow. Genuine transparent alpha background, crisp edges, flat colors. Square canvas, mark centered and filling 90 percent of canvas with small equal safe margins. This will be a 32px app icon; keep strong simple shapes. No tile background, no mockup, no labels.

### Wordmark

Use case: background-extraction. Edit target: supplied approved Animama option1 brand sheet. Extract/reproduce ONLY the exact 'Animama' wordmark from the upper right main horizontal lockup. Preserve that rounded heavy friendly lettering, capital A followed by lowercase nimama. Text verbatim: Animama. Remove icon, faces, rays, other text, swatches, labels and all other elements. Single line, wide tightly fitted canvas with minimal 3 percent clear margins, genuinely transparent alpha background. Solid black letters, no shading, no glow, no gradients. Production wordmark mask asset. Match approved letterforms faithfully, no redesign.
