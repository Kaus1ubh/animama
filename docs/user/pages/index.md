# Animama

Animama is an AI avatar companion that keeps your conversations and content in
your own local installation. Chat with an **Anima**, your companion with its own
identity and history. Its **Avatar** is the visual character you see.

## Choose how to run it

- [Desktop getting started](./desktop.md): the desktop app runs its services and
  database on your computer. It needs no Docker or source checkout.
- [Self-host quick start](./self-host.md): run the built web app with Docker
  Compose from an existing source checkout. You manage its configuration and data.

Both are local, single-owner installations. You do not need an Animama account.
AI chat needs a configured remote provider or a separate local model server;
there is no bundled offline chat model.

## Availability

Visit the [desktop download page](https://animama.ai/download) for availability.
