# Name and logo

"Animama" and the Animama logo identify this project and the builds its author,
Raymond Van, publishes. The source licence covers the code and the other
licensed material in this repository; it does not grant permission to use the
name or logo.

You may:

- refer to Animama by name, for example in an article, a comparison or a link;
- say that your project is based on, forked from or compatible with Animama;
- redistribute this repository's unmodified source with its notices intact.

If you distribute a modified build, or offer one as a service:

- give it a different name and icon, so people can tell it apart from Animama;
- change the identifiers and endpoints that point at Animama's own
  infrastructure, so that your build never uses Animama's update feed, release
  storage or model downloads: `appId` and `productName` in
  `src/frontend/desktop/electron-builder.yml`, the distributions in
  `src/frontend/desktop/runtime/release-policy.json`, and the model origin in
  `src/backend/animama/domain/model_assets.py` and
  `src/backend/animama/resources/model-assets.v1.json`;
- don't suggest that Raymond Van makes, endorses or supports it.
